About these samples

These images are reference renderings, not screenshots of the widgets running on a transmitter. The actual KSE4 and KSE5 widgets are laid out slightly differently. This gallery is intended to give users a clear reference for what each theme's colors look like. The previews use the 480×272 radio aspect ratio, and actual text spacing can also vary by radio and EdgeTX font rendering.
